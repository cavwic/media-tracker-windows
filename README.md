# Media Tracker · 采集工具

## 是什么

一款 Windows 本地图片、视频采集与管理工具，目前支持 Windows 10/11 x64。

## 能做什么

- 按人物管理多个平台、多个账号，采集 X、Instagram、Facebook、TikTok 等平台当前可访问的媒体。
- 首次下载后增量同步；已保存的媒体不会因原帖删除而自动删除。
- 本地精确去重、可选图片和视频相似去重，保留媒体的发布来源。
- 搜索媒体、用系统程序打开文件、定位文件夹及清理缓存。

## 怎么用

1. 到 [下载页面](https://github.com/cavwic/media-tracker-windows/releases/latest) 下载软件 ZIP，完整解压到可写文件夹；不要下载 `Source code`。
2. 运行 `首次编译.cmd`，按提示确认下载独立运行环境；准备完成后，以后直接运行 `采集工具.exe`。
3. 在“我的账号”中登录所需平台并验证，新建采集对象、选择保存目录、添加目标账号，然后点击同步。
4. 需要相似去重时，按提示下载组件或指定已有工具位置；取消不影响采集和精确去重。

无需管理员权限，不安装到系统、不修改注册表。移动软件时请保留整个文件夹；重要媒体请先备份。

本工具未获平台自动采集许可，请遵守平台规则与内容权利。EXE 未签名，可能出现 Windows 安全提示。
