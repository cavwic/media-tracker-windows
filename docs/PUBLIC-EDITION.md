# Media Tracker 公开发行版（最小版）

本版保留媒体采集、增量同步、本地精确去重、来源索引、查找及系统程序打开功能。相似去重组件为可选项：缺少组件时仍可采集及精确去重；点击准备入口后可选择下载、指定已有工具位置或取消。未开始处理时显示普通鼠标指针。

V1.3 仅发布 Windows x64 最小版。macOS、Linux、Windows ARM64 和 32 位 Windows 暂未接入或验证，不宣称可用。

## 独立运行

- 将本版解压到独立的新目录，运行 `首次编译.cmd`，按提示确认首次联网准备。成功启动后保留生成的 EXE，编译材料会按原有成功确认流程清理。不要以管理员身份运行，不修改注册表、系统 PATH 或 Windows 安全设置。
- 程序和登录资料均在本版目录内，首次启动没有人物、账号或媒体。不得将本版的 `data` 指向另一套自用版的 `data`，也不要复制自用版的 Cookie、浏览器资料、快捷方式或同步索引。
- 媒体输出目录也应独立；不要让两版同时读写同一人物目录及 `Index`。应用身份隔离不能保护用户主动共享的文件夹或 NAS 路径。
- 本版应用身份为 `media-tracker-public`，启动器不会转发到自用版服务。端口冲突按原有备用端口处理；关闭工具窗口会完整退出它拥有的服务及浏览器。
- 程序隔离不等于平台账号或网络隔离。使用同一平台账号、同一 IP、同一代理或手动共享资料，仍可能使平台风控影响两版。没有防封承诺、账号轮换或 IP 规避机制。

## 功能边界

- X、Instagram、Facebook、TikTok 仍是网页及网页响应采集，不是平台官方 API，也未获得这些平台对本工具的自动采集许可。能登录、能查看、能手动保存不意味着获准自动采集。
- 只用于平台规则与作品权利许可允许的访问。遇到拒绝、限流、登录失效或人工验证码应停止并由用户处理；不提供破解验证码、DRM 解密、付费访问绕过、凭据窃取或限制规避。
- 首次联网操作会显示使用须知；用户确认仅表示已阅读风险，不构成平台授权、作品授权、合法性认证或开发者免责。
- 内置 Threads 信息登记保留；尚无完整媒体下载适配器，不宣称已支持全部站点。
- 自定义平台的首版通用引擎为受限 `yt-dlp`。不集成、不分发、不自动下载 `gallery-dl`；旧的 gallery 专用配置会明确提示不支持，而不是静默换引擎。自定义登记并不保证站点可下载。
- 下载后不会因原帖被删除而自动删除已保存的媒体。精确去重按本地完整 SHA-256；相似去重有误判风险，合并副本保存在可恢复归档中，保留不同音轨版本。不能由画面质量推断作品许可或训练适用性。
- 日期及来源反映采集器实际取得的数据，不保证平台所有历史、已删除或无权访问的内容都能取得。
