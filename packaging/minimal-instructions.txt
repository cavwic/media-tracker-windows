首次使用
1. 完整解压到有写入权限的文件夹，不要在 ZIP 内直接运行。
2. 双击“首次编译.cmd”。仅使用 Windows 自带 .NET Framework 编译器，不需要 Visual Studio 或管理员权限。
3. 首次缺少 Node 时先询问，确认后下载固定官方版本，核对完整 SHA-256，再保存到本工具 runtime/node。随后缺少专用 Chromium 和采集 Python 时再次询问，确认后下载并校验。准备总下载量约 253 MB；拒绝任何一步都不启动采集、不删除编译材料，已完成组件保留。
4. 运行环境完整并确认工具窗口启动成功后，才自动清理本包编译源码、脚本和首次编译入口。之后双击“采集工具.exe”，不再调用 CMD、VBS 或 PowerShell 作为启动入口。
5. 运行环境就绪时不重复联网下载；关闭主窗口会完整退出工具自己的后台服务。登录窗口与采集都使用独立运行环境，不占用日常 Chrome/Edge。

最小公开版
包含当前语言、主题、人物/账号配置、登录绑定、内置采集、增量同步、SHA-256 精确去重、索引、打开文件、目录定位和缓存清理功能。自定义通用采集只集成 yt-dlp；gallery-dl 未集成，旧 gallery 选项会明确提示而不会暗中运行。
最小版将 Node 延迟至首次确认后下载；相似图片/视频去重暂不启用，去重入口保留原位置并显示灰色。相关本地算法体积很小，保留在包内以便安装组件后直接启用，无需重新下载采集工具或迁移媒体。
初始压缩包小不代表最终占用小：首次准备后仍需约 600 MB 磁盘空间，不包含后续下载媒体、缓存或可选去重组件。

按需启用一键去重
点击灰色“一键去重”时提示“当前无一键去重功能，是否需要下载工具包？”；选“否”或关闭提示不会下载。
选“是”后下载已固定版本的 FFmpeg 与 ffprobe，核对 SHA-256，保存到软件所在目录的 tools/ffmpeg-<版本>/bin，再做运行及能力检查。成功后启用去重入口，本次不会自动开始去重，需再次主动点击。
下载失败或取消时保留原媒体、登录资料和已完成运行组件，入口继续保持未启用，可稍后重试。最小版不会因系统 PATH 中碰巧存在工具而隐式启用；已有工具可在“我的账号 > 去重组件”显式指定完整 bin 目录。
同步所需的精确 SHA-256 去重一直可用；相似去重缺少工具时不妨碍采集，不会在每次同步时自动下载或反复弹窗。
去重均在本机执行，不上传媒体、哈希或索引，不使用在线模型或 AI 服务。工具下载和媒体采集仍需要网络。

保留文件与数据
这不是单文件 EXE。不要删除 app、runtime、components、licenses、data 或 tools 内正在使用的文件。
移动软件时请一起移动整个文件夹；人物媒体路径（包括 NAS）不会自动改变。正常关闭后再移动或更新，不要覆盖正在运行的版本。
发布 ZIP 不包含作者账号、登录资料、人物配置、媒体或索引。首次使用需配置自己的账号；更新自己的旧版本时请先完整退出并备份自己的 data，不要把旧 data 放入公开压缩包。
本包自动清理只针对未改动的编译材料，不清理 data、媒体或运行组件。编译失败、启动失败、被安全策略阻止时保留源码和 data/startup-logs，解决后重试，不用管理员权限作为默认修复方式。
