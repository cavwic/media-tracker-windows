首次使用
1. 完整解压到你有写入权限的文件夹，不要在 ZIP 中直接运行。
2. 双击“首次编译.cmd”。只使用 Windows 自带的 .NET Framework 编译器，不需要 Visual Studio 或管理员权限。
3. 首次缺少专用浏览器和 Python 时会先询问。确认后联网下载固定版本（约 217 MB），校验 SHA-256 后解压到本工具 runtime 文件夹；不使用系统 Chrome/Edge，不安装到系统、不修改注册表或全局 PATH。编译本身在本机完成。
4. 运行依赖完整、离线验证通过后自动启动“采集工具.exe”。只有收到工具窗口启动成功确认，才清理本包的编译源码、脚本和首次编译入口。
5. 后续直接双击“采集工具.exe”。运行依赖已就绪时不重复联网下载。关闭工具主窗口会退出工具自己的后台服务，不关闭你的日常浏览器。

本版包含原采集工具最新的语言、UI 和主题功能。标准版预置独立 Node，去重入口保留原功能；相似去重的 FFmpeg 与 ffprobe 仍按需询问安装，不打进初始 ZIP。另提供更小的“最小版”：Node 在首次确认后准备，未启用相似去重时按钮灰色可点击询问下载；采集与精确去重不受影响。

包体与磁盘空间
精简 ZIP 约 40 MB，包含 Node、工具代码和编译入口，并非完整离线包。首次准备需要访问固定的官方组件来源；准备后实际磁盘占用仍是数百 MB，不是 40 MB。
首次拒绝、取消或下载失败时，不启动采集、不删除编译材料。已完整安装的组件可供重试，未完成临时文件会按本次操作安全清理。不要删除 runtime 中的运行文件来“清理缓存”。
编译材料清理后若运行依赖缺失，EXE 会再次检查并询问准备；不静默下载、不改用你的日常浏览器。保留 Node 和 app，否则应从原 ZIP 恢复运行文件并保留 data。

保留运行文件
这是包含独立运行环境的便携文件夹，不是单文件 EXE。不要删除 app、runtime、components、licenses、data 或其他运行文件。“清理编译文件”不删除这些内容。
EXE 和整个文件夹可以一起移动。绑定账号会话保存在本包 data 中；目标媒体路径（包括 NAS 路径）不会因移动自动改变。
编译失败、被安全策略阻止或启动失败时，保留编译材料和 data/startup-logs 日志；解决问题后重试。不要删除 EXE 来清理缓存，也不要用管理员权限作为默认修复方式。

去重组件
精确 SHA-256 去重由工具内置实现，不需要 FFmpeg 或模型。
相似图片/视频去重需要 FFmpeg 和 ffprobe。工具缺少组件时先询问你：确认后才从官方构建提供方下载已固定版本并验证 SHA-256，默认保存到本工具 tools 文件夹，或使用你选择的位置。
不安装也可在“我的账号 > 去重组件”指定已安装 FFmpeg 的 bin 文件夹。所选程序会运行版本/能力验证。缺少组件不影响媒体采集和精确去重。
组件下载需要网络，媒体去重本身在本机完成，不上传媒体、哈希、索引，不调用 AI 服务。

安全说明
本地编译产生的是未签名 EXE，并不会使 Windows 自动信任。Smart App Control、企业应用控制或杀毒软件仍可能阻止运行；本包不会关闭安全保护、解除文件安全标记、导入自签名证书或修改注册表。
从互联网下载的 ZIP 解压后，编译脚本也可能保留网络来源标记，被 PowerShell RemoteSigned 等执行策略阻止。本地编译不解决这种限制；遇到阻止会保留材料，不自动绕过策略。此方案不保证“下载后所有电脑直接运行”。
本包不包含作者的账号登录资料、人物资料、NAS 媒体或历史索引，首次使用需要配置自己的账号。
公开发布前仍应完成目标系统验证、发布主体签名方案及第三方再分发许可证审查。此测试包不是“所有 Windows 零拦截”的承诺。

更新
保存 data 及媒体。新版解压到新目录后按发布说明更新；不要覆盖正在运行的版本。编译源码已清理时，需要从原 ZIP 恢复对应版本的 compile 和首次编译入口后重新编译，不要覆盖未知 EXE。
