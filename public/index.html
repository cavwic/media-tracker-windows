查看结果与保留规则

只在同一人物内合并高置信度的同内容图片或完整视频。保留版本参考分辨率、清晰度和内容完整性，不保证适合 LoRA 训练；裁剪、编辑、音轨不同或判断不充分的版本保留。疑似版本已保留，不影响采集完成，无需处理也可继续同步。

合并版本移到人物 Index/DedupArchive，发布来源与恢复记录保留。归档仍占磁盘空间，不会自动永久删除。

下方疑似项可单击文件名用系统关联程序检查，右键可打开文件位置或查看来源；全人物或单个人物的去重都可安全停止。

    界面主题

    所有工具窗口保持一致

    右上角可随时切换语言和主题。选择系统语言时，Windows 显示语言为中文则使用中文，否则使用英文；选择系统主题会随 Windows 深浅色自动切换。手动选择可覆盖系统设置。

    本地媒体整理

    新同步文件自动比对

    同步保存后自动与同一人物的媒体比对，图片与视频均包含。保留版本参考可测量的分辨率、清晰度与完整性，不是 LoRA 训练适配结论。无法确认的疑似项保留，合并版本进入 Index/DedupArchive 可恢复归档；账号登录资料不参与去重。

    可选本地组件

    图片与视频去重组件

    精确去重无需额外安装。相似去重使用 FFmpeg 与 ffprobe，不需要 AI 模型；缺少组件时先询问，不会自动安装。

    点击设置可检查组件或指定已有工具的位置。

    连接新账号

    不登录也可尝试部分公开内容；敏感媒体、受限页面和完整历史通常需要登录。Google、Apple、Facebook 等关联登录会在工具自己的窗口中完成。

    保存时建立人物目录和 Index 来源索引目录。图片、视频目录在首次成功下载时按需创建；移除平台或账号不会删除媒体或历史来源。

    使用现有登录绑定

    导入已关注账号

    从“我的账号”中选择登录绑定，读取当前可访问的关注列表。所选账号只加入当前人物草稿，保存人物后生效；不会自动关注或下载媒体。

    可依次读取不同平台的登录绑定。请只勾选属于同一个人物的账号；工具不会按相似名称自动合并人物。

    全局平台

    添加自定义平台

    创建后，所有人物和“我的账号”都能选择此平台。平台名称只用于归档；能否采集需用目标账号链接测试。

    平台主页域名创建后固定，以隔离登录资料。修改名称不会更改登录资料或媒体位置；如需其他网站，请新建平台。

    登录在工具专用窗口中完成，也可在站点内使用第三方关联登录。打开页面不等于登录成功，之后仍需点击“验证登录”。

    填写当前登录账号的关注列表页面，使用平台域名下的 HTTPS 地址。未填写时仍可手动添加账号和同步媒体；填写后会尝试读取页面上的账号链接，不保证任意网站都支持。

    高级：登录验证规则（需要登录时配置）

    本版自定义平台需配置登录后专有标记，并用独立匿名页面对照；匿名时应出现未登录标记，或跳转到登录页。不能使用 body 或通用导航。未配置、匿名也能看到同一标记或对照失败时，不会判为已登录。修改规则后需重新验证关联账号。
